# 钓鱼经验机

一个在 Windows 本地运行的钓鱼视觉助手。使用中央水花变化判断咬钩，分别控制普通收竿和换饵等待；提供中文界面、区域校准、录像回放、全局热键与运行记录。

当前版本 **0.1.0**。已完成录像回放与状态逻辑验证；尚未在实服验证截图兼容性、输入是否被接受及自动钓鱼成功率。

## 启动

当前工作目录为 `D:\钓鱼经验机`，依赖已经安装。双击 **`start.cmd`** 即可打开。

在新电脑安装时，需要 Windows、64 位 Python 3.11+，在项目目录的 PowerShell 中运行：

```powershell
.\setup.ps1
```

虚拟环境、缓存、日志和本地配置均写入项目文件夹。原始录像使用本地路径读取，不上传。

## 第一次使用

1. 在游戏中装备台竿，站稳并保持固定朝向。使用窗口化或无边框窗口，避免界面遮挡游戏画面。
2. 在助手中选择正确的游戏窗口。默认区域来自 1728×1080 录像，会按窗口大小缩放；改变视角、落点、界面缩放后应重新框选。
3. “框选水花区域”会等待 3 秒，让你切回游戏，然后在截图上拖动框选。选自己的鱼浮落点周围，避开其他玩家和界面文字。
4. “框选鱼饵数字”只框右下角最后一位数字（0～5），不要包含 `/∞`。默认模板来自原录像的六种数字。
5. 先使用 **识别预览**：手动甩竿并右键放大，按 F8，5 秒内切回游戏。检测到一次水花信号后停止预览，不会点击鼠标。
6. 切换 **自动循环** 后，正常从“鱼竿已就绪、尚未甩竿”开始。若接管已经入水且已经放大的鱼竿，勾选对应选项。

**F8** 开始/暂停，**F9** 停止。切出所选游戏窗口、窗口关闭、截图或输入出错、等待超时都会暂停。重启后重新确认状态；按住右键模式会释放由程序按住的鼠标键。

如果 F8/F9 已被其他软件占用，会自动尝试 Ctrl+Alt+F8 / Ctrl+Alt+F9，实际可用热键会显示在按钮和底部。若两种组合均被占用，界面会提示；可使用暂停按钮或切出游戏停止。

“单击切换 / 按住右键 / 手动放大”要与游戏操作方式一致。当前默认单击切换，每次甩竿后 0.7 秒操作右键。录像中提竿时镜头退出放大，但没有按键日志，不能确认这是游戏自动行为还是人工操作，需要在预览和手动操作中核对。

## 依据录像设置的默认节奏

所有等待均从本轮对应动作发出时计算；不是从水花首次出现或上一轮抛竿时累计。

| 参数 | 默认值 | 依据 |
|---|---:|---|
| 普通提竿 → 下一次抛竿 | **2.8 秒** | 视频实际间隔约 2.0～2.6 秒，留出余量 |
| 提竿＋换饵 → 下一次抛竿 | **4.8 秒** | 视频该轮约 4.3 秒，留出余量 |
| 抛竿后水花屏蔽 | **3.5 秒** | 入水水花约在抛竿后 2.3 秒出现，约 3.1 秒降至阈值以下 |
| 平静确认 | **0.2 秒** | 屏蔽结束后，等残余水花消退再开始监测 |
| 检测频率 | 30 次/秒 | 局部截图；至少两帧且满足确认时间才产生信号 |

启用鱼饵识别时，程序以稳定、近期的识别值更新鱼饵。最后一饵提竿后，或画面出现 0，进入较长等待；计时结束后仍需看到可用鱼饵才抛竿。等待超时后暂停，不会对 0 饵继续点击。

关闭鱼饵识别时采用内部计数，起始数量由“手动初始鱼饵”指定。手动操作、失败或漏钓可能造成计数错位，此模式需要自行重置。界面里的“提竿信号”统计的是检测触发次数，不是已确认的获鱼数量。

## 离线录像回放

界面“录像验证”中选择视频，并填写录像中的甩竿起点（秒）。默认六个时间仅对应已分析的 `record20260912-233726.mp4`；更换录像后必须重新标注。

命令行示例：

```powershell
.\.venv\Scripts\python.exe -m fishing_assistant --replay 'D:\你的录像.mp4' --cast-times '1.85,11.20,24.65,35.20,46.20,58.70'
```

回放复用实时检测的 `SplashGate`，不会导入或调用鼠标输入模块。结果写入 `logs/replay_latest.json`。

已分析录像为 69.05 秒、60 fps、1728×1080。当前应用回放产生 6 次信号：约 8.22、22.33、32.85、43.90、54.12、67.08 秒，均位于人工核对的咬钩片段。选出的稳定区间中，292 个鱼饵数字样本均识别一致。

这些区域、阈值与数字模板来自同一段录像，属于样本内验证，不能代表其他水域、光照、画质、缩放下的准确率。详见 [录像分析](analysis/zoom/分析结论.md) 与 [应用回放结果](analysis/zoom/app_replay.json)。

## 开发与验证

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

- `fishing_assistant/engine.py`：计时、屏蔽、去重、普通/换饵等待与超时。
- `vision.py`：水花面积、数字模板识别和读数稳定确认。
- `windows.py`：窗口坐标、F8/F9 热键、标准 Windows 鼠标输入。
- `runtime.py`：局部截图与执行；每次输入前检查前台窗口。
- `gui.py`：中文桌面界面、框选区域、参数和回放。
- `analysis/`：录像测量结果与证据。

程序使用普通屏幕截图与 Windows 输入接口，没有反作弊绕过功能。游戏可能限制或拦截此类自动化，使用前应核对所在服务器规则。标准输入接口被接受也不代表游戏允许此玩法自动化。
