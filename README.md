# 钓鱼经验机

《三角洲行动》台竿钓鱼辅助工具：本地 OpenCV 识别水花，自动抛竿、长按右键放大、提竿和等待换饵。

**v0.1.3 · Windows x64 · Python 3.11+ · [MIT](LICENSE)**

## 安装与使用

1. 安装 64 位 Python 3.11+，下载源码到独立文件夹。
2. 在项目目录打开 PowerShell，运行 `.\setup.ps1` 安装依赖。
3. 双击 `start.cmd`。如果游戏以管理员权限运行，助手也需右键 **“以管理员身份运行”**。
4. 选择游戏窗口，先用 **“识别预览”** 检查水花和鱼饵区域。预览不点击鼠标，需要自己抛竿并按住右键。
5. 确认识别正常后收回鱼竿，选择 **“自动循环”**，点击开始，**5 秒内切回游戏**。

已内置 2560 × 1600 画面下实测可用的两个区域，会按窗口尺寸缩放。**先试默认位置，不匹配时再框选。** 更换视角、分辨率或界面缩放后需重新检查。

**F8 开始/暂停，F9 停止**；热键冲突时使用界面显示的备用组合键。切出游戏、异常或超时会暂停，并松开程序按住的鼠标键。

## 选点与框选

### 水花区域

- **尽量找无反光、波纹少、光照稳定的水面**，避开高光倒影、持续泡沫和其他玩家的水花。
- 点击“框选水花区域”，在 **3 秒内切回游戏并按住右键放大**，然后在静态截图上拖动选框；松开左键保存，Esc 取消。
- 以自己的鱼浮落点为中心，覆盖完整咬钩水花并留少量余量。避开岸边、天空、文字和人物；预置区域干扰较多时可适当缩小。
- 勾选“显示识别到的亮色区域”：**平静时亮色比例应低于平静上限，咬钩时应高于触发面积**。如果整片水面都被标记，先换位置或调整区域，再调亮度阈值。

![入水、平静与咬钩水花对比](analysis/zoom/splash_evidence.png)

### 鱼饵数字

- 等数字稳定显示，点击“框选鱼饵数字”，3 秒内切回游戏后框选。
- **只选最后一位 0～5**：例如 `005 / ∞` 中的 **5**，不要包含前导 `00`、`/∞` 或附近图标。
- 保留完整笔画和少量空白，宽度要能容纳较宽的数字，不能按 `1` 的宽度框死。
- 勾选“显示鱼饵裁剪”检查实际图片，确认白色数字、红色低饵量数字及换饵后的 `5` 都能读对。

## 动作与默认节奏

| 操作 | 默认设置 |
|---|---|
| 抛竿 | 左键点按两次，第一次松开后间隔 0.15 秒 |
| 放大 | 抛竿后 0.7 秒按住右键，提竿前松开 |
| 提竿 | 左键点按一次 |
| 普通提竿 → 再抛竿 | 2.8 秒 |
| 提竿＋换饵 → 再抛竿 | 4.8 秒，并确认有可用鱼饵 |
| 入水水花屏蔽 | 3.5 秒，随后确认平静 0.2 秒 |
| 检测频率 | 30 FPS |

等待时间可按实际情况调整；保持“右键放大方式”为 **按住右键**。首次使用先观察一轮完整流程，再检查最后一饵后的换饵循环。

## 硬件与内存

无需独立显卡、CUDA 或视觉模型；使用 CPU 处理。建议在游戏之外为助手预留 **1～2 GiB 内存、1 GiB 磁盘空间**。安装依赖需要网络，运行识别不需要云端服务。

## 常见问题

| 现象 | 处理 |
|---|---|
| 鱼饵未确认，尚未点击 | 查看鱼饵裁剪并重新框选；此时程序还没发出点击 |
| 一直等待平静或亮色超标 | 避开反光，检查区域和亮度阈值 |
| 有水花但不提竿 | 确认自动循环模式、水花在框内，且已结束入水屏蔽 |
| 点击无反应 | 用“单次左键测试”排查；检查窗口和运行权限，该测试只点一次 |
| 游戏失去前台焦点 | 在倒计时内切回所选游戏窗口，运行时不要切出 |
| 更新后没变化 | 关闭旧助手，重新启动并核对版本号 |

参数保存在 `local_config.json`，日志和鱼饵裁剪在 `logs/`，均不会自动上传。反馈问题时附版本、分辨率、操作步骤和脱敏后的日志片段。

## 开发与验证

运行测试：`.\.venv\Scripts\python.exe -m unittest discover -s tests -v`。界面支持离线录像验证，需填写对应视频的抛竿时间，并使用匹配的区域和阈值。参见 [录像分析](analysis/zoom/分析结论.md)。

默认参数来自有限实测，不保证适配所有场景。“提竿信号”不等于成功获鱼数。
