# 钓鱼经验机

《三角洲行动》台竿钓鱼辅助工具：本地 OpenCV 识别水花，自动抛竿、长按右键放大、提竿和等待换饵。

**v0.1.3 · Windows x64 · Python 3.11+ · [MIT](LICENSE)**

## 安装与使用

1. 安装 64 位 Python 3.11+（包含 pip 和 Tcl/Tk），下载并解压源码到独立文件夹。
2. 在包含 `setup.ps1` 的项目目录打开 PowerShell，执行：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
   ```

   脚本会创建项目专用的 `.venv` 环境，并自动安装全部依赖，**无需提前单独安装 NumPy 等库**。命令中的执行策略仅对本次 PowerShell 进程生效。

3. 双击 `start.cmd`。如果游戏以管理员权限运行，助手也需右键 **“以管理员身份运行”**。
4. 选择游戏窗口，先用 **“识别预览”** 检查水花和鱼饵区域。预览不点击鼠标，需要自己抛竿并按住右键。
5. 确认识别正常后收回鱼竿，选择 **“自动循环”**，点击开始，**5 秒内切回游戏**。

已内置 2560 × 1600 画面下实测可用的两个区域，会按窗口尺寸缩放。**先试默认位置，不匹配时再框选。** 更换视角、分辨率或界面缩放后需重新检查。

**F8 开始/暂停，F9 停止**；热键冲突时使用界面显示的备用组合键。切出游戏、异常或超时会暂停，并松开程序按住的鼠标键。

### 依赖与缺失模块

依赖包括 **NumPy、OpenCV（`opencv-python-headless`）、Pillow、mss、imageio-ffmpeg**，具体版本以 [requirements.txt](requirements.txt) 为准，由上述安装命令统一安装。

若提示 `ModuleNotFoundError`，例如缺少 `numpy`、`cv2` 或 `PIL`，在项目目录执行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\start.cmd
```

若找不到 `.venv\Scripts\python.exe`，先重新执行第 2 步。请使用 `start.cmd` 启动，避免切换到未安装依赖的其他 Python 环境。若缺少 `tkinter`，需通过 Python 安装程序补装 Tcl/Tk 组件。

## 选点与框选

### 水花区域

- **尽量找无反光、波纹少、光照稳定的水面**，避开高光倒影、持续泡沫和其他玩家的水花。
- 点击“框选水花区域”，在 **3 秒内切回游戏并按住右键放大**，然后在静态截图上拖动选框；松开左键保存，Esc 取消。
- 以自己的鱼浮落点为中心，覆盖完整咬钩水花并留少量余量。避开岸边、天空、文字和人物；预置区域干扰较多时可适当缩小。
- 勾选“显示识别到的亮色区域”：**平静时亮色比例应低于平静上限，咬钩时应高于触发面积**。如果整片水面都被标记，先换位置或调整区域，再调亮度阈值。

![入水、平静与咬钩水花对比](analysis/zoom/splash_evidence.png)

### 鱼饵数字

- 等数字稳定显示，点击“框选鱼饵数字”，3 秒内切回游戏后框选。
- **只选最后一位 0～5**：例如 `005 / ∞` 中的 **5**，不要包含前导 `00`、`/∞` 或附近图标。
- 保留完整笔画和少量空白，宽度要能容纳较宽的数字，不能按 `1` 的宽度框死。
- 勾选“显示鱼饵裁剪”检查实际图片，确认白色数字、红色低饵量数字及换饵后的 `5` 都能读对。

## 按水面情况调参

**先暂停，每次只改一个参数，保存后重新开始“识别预览”**；运行中的参数不会立即更新。自己抛竿并按住右键，勾选“显示识别到的亮色区域”，观察普通水面和咬钩水花的标记、亮色百分比。

程序按“够亮、颜色够淡”的像素占比判断水花。先让真正的水花被标记，再调整触发面积；**水花都没被标记时，只降低触发面积通常无效**。

| 参数 | 默认值 | 调整作用 |
|---|---|---|
| 亮度下限 | 80 | 降低可识别更暗的水花；提高可排除较暗的水面，但也可能漏掉水花 |
| 饱和度上限 | 100 | 提高会接受颜色更浓的像素；降低可排除有颜色的干扰，对白色反光无效 |
| 水花触发面积 | 约 0.8% | 降低更易触发，也更易误提竿；提高可过滤较小的亮色干扰 |
| 平静面积上限 | 约 0.4% | 入水屏蔽后，亮色占比需持续低于此值才能进入检测；必须小于触发面积 |

下面数值是**逐步试调示例，不是通用预设**；从自己的当前值小步调整。

| 水面情况 | 优先处理 | 参数怎么试 |
|---|---|---|
| **反光明显** | 换朝向或钓点，框内避开高光倒影，保留完整咬钩水花 | 若反光比水花暗，亮度下限可试 `80 → 100 → 120`，确认水花仍被标记；若只剩小块反光误触发，再将触发面积试调 `0.8 → 1.0 → 1.2` |
| **水面很暗，有水花不提竿** | 检查水花是否在框内、是否被标记 | 水花未被标记，先将亮度下限试调 `80 → 70 → 60`；已被标记但占比不够，再将触发面积试调 `0.8 → 0.6 → 0.5`。若水花明显带色，饱和度上限可试 `100 → 120` |
| **大波纹、亮色浪尖误触发** | 缩小区域以排除无关浪尖，仍需覆盖完整水花；持续翻浪时优先换钓点 | 观察普通浪尖的占比峰值，将触发面积逐步提高，例如 `0.8 → 1.0 → 1.2`，同时确保真正的咬钩水花还能超过它 |

- **一直“等待平静”**：先排除反光、泡沫和框选干扰。若普通水面的占比仍稍高，可适当提高平静面积上限；它应高于平静水面占比、低于触发面积，不能为了进入检测一直上调。
- **阈值怎么定**：触发面积应高于普通波纹的峰值、低于咬钩水花的峰值，并留余量。若两者反复重叠，仅靠这些参数很难稳定区分，应换位置或重新框选。
- **面积单位**：界面填 `0.5` 表示 **0.5%**，占比以框选区域为分母；改变框选大小后要重新检查阈值。

## 动作与默认节奏

抛竿左键点按两次，第一次松开后间隔 0.15 秒；提竿前松开右键，左键点按一次。保持“右键放大方式”为 **按住右键**。

| 参数 | 默认值 | 何时调整 |
|---|---|---|
| 普通提竿 → 抛竿 | 2.8 秒 | 收鱼动画没结束就抛竿，每次增加 0.2～0.5 秒 |
| 提竿＋换饵 → 抛竿 | 4.8 秒，并确认有可用鱼饵 | 最后一饵后抛得太早，每次增加 0.2～0.5 秒；同时检查换饵后的 `5` 能否识别 |
| 抛竿后屏蔽 | 3.5 秒 | 入水水花尚未散去就误提竿，可试 4.0 秒；过长会漏掉早来的咬钩，暗水漏检不靠缩短它解决 |
| 抛竿后右键 | 0.7 秒 | 抛竿动作影响放大时，每次增加 0.1～0.2 秒；改变后重新检查放大视角下的区域 |
| 平静确认 | 0.2 秒 | 入水后短暂平静便过早进入检测，可试 0.3～0.5 秒；只影响进入检测的时机，不能过滤检测开始后的大波纹 |
| 检测频率 | 30 FPS | CPU 占用需要降低时可试 20；降低可能漏掉短促水花，不用于提高灵敏度 |
| 等待咬钩超时 | 60 秒 | 确认该钓点确实等得更久时再增加；反复漏检应先校准识别参数 |

“识别鱼饵数字并确认换饵完成”建议保持开启；关闭时，“手动初始鱼饵”需填写开始时的实际剩余量（1～5）。调完先观察几轮，再检查最后一饵后的换饵循环。

## 硬件与内存

无需独立显卡、CUDA 或视觉模型；使用 CPU 处理。建议在游戏之外为助手预留 **1～2 GiB 内存、1 GiB 磁盘空间**。安装依赖需要网络，运行识别不需要云端服务。

## 常见问题

| 现象 | 处理 |
|---|---|
| 鱼饵未确认，尚未点击 | 查看鱼饵裁剪并重新框选；此时程序还没发出点击 |
| 一直等待平静或亮色超标 | 按上方“按水面情况调参”检查区域、亮度和平静面积上限 |
| 有水花但不提竿 | 确认自动循环模式、已结束入水屏蔽并进入检测；再按上方暗水面步骤检查标记和占比 |
| 点击无反应 | 用“单次左键测试”排查；检查窗口和运行权限，该测试只点一次 |
| 游戏失去前台焦点 | 在倒计时内切回所选游戏窗口，运行时不要切出 |
| 更新后没变化 | 关闭旧助手，重新启动并核对版本号 |

参数保存在 `local_config.json`，日志和鱼饵裁剪在 `logs/`，均不会自动上传。反馈问题时附版本、分辨率、操作步骤和脱敏后的日志片段。

## 开发与验证

运行测试：`.\.venv\Scripts\python.exe -m unittest discover -s tests -v`。界面支持离线录像验证，需填写对应视频的抛竿时间，并使用匹配的区域和阈值。参见 [录像分析](analysis/zoom/分析结论.md)。

默认参数来自有限实测，不保证适配所有场景。“提竿信号”不等于成功获鱼数。
